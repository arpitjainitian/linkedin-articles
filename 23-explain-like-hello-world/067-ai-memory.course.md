# Lesson 23.67: AI memory (course companion)

*Explain It Like Hello World. Not for LinkedIn.*

## Learning objective

After this lesson, you can explain AI memory with a hello-world example, say how it really works in one step, and name its most common misunderstanding.

## The hello world, to retell

A good hotel remembers you prefer a quiet room and green tea. The staff didn't change their brains; they wrote it in your guest file and check it when you arrive.

## One step further

As you chat, the app picks out facts worth keeping ("vegetarian", "works in finance", "prefers short answers") and stores them. Next time, it fetches the relevant ones and adds them to the prompt. Some apps also keep summaries of past conversations.

The model itself is unchanged. Memory is a filing system around it, which means it can store wrong or outdated facts too.

## Exercise

Explain AI memory to someone non-technical in under one minute, using your own everyday example (not the one from the article). Then name one product where they have already met it.

## Quiz

1. What is the hello-world example for AI memory? *AI memory is that guest file, read back at the start of each chat.*
2. What is it not? *It isn't the AI learning or retraining. And it should be visible: good apps let you see, edit and delete what's remembered. (Series 12 covers memory pitfalls.)*
3. Name one place you've already met it. *Chat apps that say "memory updated". Assistants that remember your name, preferences or ongoing projects.*

## Glossary

- **Short-term memory:** the current chat on the AI's desk.
- **Long-term memory:** facts saved across chats.
- **Memory retrieval:** fetching the right saved facts when needed.
