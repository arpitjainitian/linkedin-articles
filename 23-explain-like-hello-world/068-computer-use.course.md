# Lesson 23.68: Computer use (course companion)

*Explain It Like Hello World. Not for LinkedIn.*

## Learning objective

After this lesson, you can explain computer use with a hello-world example, say how it really works in one step, and name its most common misunderstanding.

## The hello world, to retell

Ask an AI: "Fill in this expense form." It takes a screenshot, finds the "Amount" box, clicks it, types ₹1,180, takes another screenshot to check, and moves to the next box.

## One step further

The AI is multimodal (write-up 72), so it can read a screenshot. It decides the next action, such as click at this spot or type this text, and a program carries it out. Then a new screenshot shows what changed.

It's slower than using an API, but it works with any app that has a screen, including old systems with no API at all.

## Exercise

Explain computer use to someone non-technical in under one minute, using your own everyday example (not the one from the article). Then name one product where they have already met it.

## Quiz

1. What is the hello-world example for computer use? *Look, decide, click, look again. That's computer use.*
2. What is it not? *It's not a person; it can misclick, misread or be fooled by text on a web page. Run it in a sandbox, with confirmations before anything irreversible (Series 16).*
3. Name one place you've already met it. *Browser assistants that book or fill in things for you, and computer-use features in AI tools from several major providers.*

## Glossary

- **GUI:** graphical user interface: the buttons and boxes on a screen.
- **Screenshot loop:** look, act, look again.
- **Sandbox:** a safe, separate computer for the agent to work in.
