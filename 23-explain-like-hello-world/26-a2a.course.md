# Lesson 23.26: A2A (agent-to-agent) (course companion)

*Explain It Like Hello World. Not for LinkedIn.*

## Learning objective

After this lesson, you can explain A2A (agent-to-agent) with a hello-world example, say how it really works in one step, and name its most common misunderstanding.

## The hello world, to retell

Your travel agent needs a visa agent's help. First, they swap business cards: "I'm the visa agent, I can check requirements and book appointments, here's how to reach me." Then they hand over the task and get updates until it's done.

## One step further

Each agent publishes a "card" describing what it can do and how to contact it. Another agent reads the card, sends a task, and gets progress updates and results in an agreed format, even if the two were built by different teams on different tools.

Google introduced the Agent2Agent protocol in 2025, and it's now developed as an open project. It complements MCP: MCP connects an agent to tools and data (Series 11); A2A connects agents to other agents.

## Exercise

Explain A2A (agent-to-agent) to someone non-technical in under one minute, using your own everyday example (not the one from the article). Then name one product where they have already met it.

## Quiz

1. What is the hello-world example for A2A (agent-to-agent)? *A2A is how AI agents swap business cards and hand over tasks.*
2. What is it not? *A2A doesn't make agents trustworthy. Each agent still needs permissions and checks (Series 15 covers multi-agent pitfalls; Series 16 what agents are allowed to do).*
3. Name one place you've already met it. *Early enterprise tools where, say, a hiring agent asks a separate background-check agent to do its part.*

## Glossary

- **Agent card:** an agent's public description: what it does, how to reach it.
- **Protocol:** an agreed set of rules for talking.
- **Task hand-off:** one agent passing work to another.
