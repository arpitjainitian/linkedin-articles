# Lesson 23.7: Foundation model (course companion)

*Explain It Like Hello World. Not for LinkedIn.*

## Learning objective

After this lesson, you can explain foundation model with a hello-world example, say how it really works in one step, and name its most common misunderstanding.

## The hello world, to retell

Building a house, a shop and a school: you could pour a new foundation for each. Or pour one huge, strong foundation and build all three on top.

## One step further

Before, companies trained a separate model for each job: one for translation, one for summaries, one for support emails. A foundation model learns general skills once, at great cost. Then teams adapt it cheaply with prompts (write-up 19) or fine-tuning (write-up 33).

The term was popularised by Stanford researchers in 2021. GPT, Claude, Gemini and Llama are all foundation models.

## Exercise

Explain foundation model to someone non-technical in under one minute, using your own everyday example (not the one from the article). Then name one product where they have already met it.

## Quiz

1. What is the hello-world example for foundation model? *A foundation model is one big base that many AI products are built on.*
2. What is it not? *A foundation model isn't a finished product. It needs adapting, testing and guardrails for each use. And any flaw in the foundation shows up in everything built on it.*
3. Name one place you've already met it. *Every app "built on" a well-known model. The same model powering a chatbot, a coding tool and a writing assistant.*

## Glossary

- **Foundation model:** a large, general model used as a base for many tasks.
- **Adaptation:** shaping it for a task with prompts or fine-tuning.
- **Downstream task:** the specific job it's adapted for.
