# Lesson 23.89: Open-weight model (course companion)

*Explain It Like Hello World. Not for LinkedIn.*

## Learning objective

After this lesson, you can explain open-weight model with a hello-world example, say how it really works in one step, and name its most common misunderstanding.

## The hello world, to retell

A restaurant dish: you can eat it, but only at the restaurant, and you never see the recipe. That's a **closed** model, used through an app or API.

## One step further

"Open weights" means the trained model file is shared, often with a licence that has conditions. It usually doesn't mean the training data or full training method is shared; that would be fully "open source" in the strict sense, which is rarer.

Open-weight models give control, privacy and no per-question fee, but you run the servers. Closed models are easier and often more capable, but you depend on the provider.

## Exercise

Explain open-weight model to someone non-technical in under one minute, using your own everyday example (not the one from the article). Then name one product where they have already met it.

## Quiz

1. What is the hello-world example for open-weight model? *That's the difference between closed and open-weight AI models.*
2. What is it not? *Open-weight isn't automatically "free for anything". Read the licence. And it isn't automatically safer or less safe; that depends on how you run it.*
3. Name one place you've already met it. *Model families like Llama, Mistral, Qwen or DeepSeek that you can download, versus services you can only use through an API.*

## Glossary

- **Weights:** the trained knobs; the model itself.
- **Licence:** the rules for how you may use the weights.
- **Self-hosting:** running the model on your own servers.
