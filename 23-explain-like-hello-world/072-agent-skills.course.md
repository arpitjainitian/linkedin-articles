# Lesson 23.72: Agent skills (course companion)

*Explain It Like Hello World. Not for LinkedIn.*

## Learning objective

After this lesson, you can explain agent skills with a hello-world example, say how it really works in one step, and name its most common misunderstanding.

## The hello world, to retell

A new joiner gets a binder of how-tos: how we file expenses, how we write a client report. They don't memorise it. They open the right page when the task comes up.

## One step further

Each skill has a short description plus detailed steps. The agent sees the short descriptions, and when a task matches, it opens the full skill. That keeps the agent's desk clear (write-up 25) while giving it expert steps on demand.

Skills hold know-how: how to do something. Tools (write-up 70) and MCP (write-up 71) give access: what the agent can reach. Agents usually need both.

## Exercise

Explain agent skills to someone non-technical in under one minute, using your own everyday example (not the one from the article). Then name one product where they have already met it.

## Quiz

1. What is the hello-world example for agent skills? *Agent skills are that binder, for an AI agent.*
2. What is it not? *A skill isn't a new model or new training. It's instructions the same AI reads. Skills from unknown sources can carry hidden instructions, so review them like code.*
3. Name one place you've already met it. *AI assistants that follow your company's report format or brand rules, and coding agents with team-specific playbooks.*

## Glossary

- **Skill:** packaged know-how an agent loads when needed.
- **Playbook:** step-by-step instructions for a task.
- **Progressive loading:** opening the details only when they're relevant.
