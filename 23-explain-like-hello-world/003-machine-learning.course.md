# Lesson 23.3: Machine learning (course companion)

*Explain It Like Hello World. Not for LinkedIn.*

## Learning objective

After this lesson, you can explain machine learning with a hello-world example, say how it really works in one step, and name its most common misunderstanding.

## The hello world, to retell

Try writing rules for spotting spam: "contains FREE", "has many exclamation marks"... Spammers change, and your rules break.

## One step further

You give the computer examples and the right answers. It adjusts itself until its guesses match the answers. Then it can label new emails it has never seen.

The same idea predicts house prices, recommends films, flags fraud and reads X-rays. The quality depends heavily on the examples: bad or biased examples teach bad or biased patterns.

## Exercise

Explain machine learning to someone non-technical in under one minute, using your own everyday example (not the one from the article). Then name one product where they have already met it.

## Quiz

1. What is the hello-world example for machine learning? *Machine learning learns the patterns from examples instead.*
2. What is it not? *Machine learning doesn't understand the way people do. It finds patterns, including accidental ones. If every "spam" example came on Mondays, it might learn "Monday means spam".*
3. Name one place you've already met it. *Gmail's spam folder, Netflix recommendations, fraud alerts from your bank.*

## Glossary

- **Training data:** the examples the computer learns from.
- **Label:** the right answer attached to an example.
- **Model:** what the computer ends up with after learning.
