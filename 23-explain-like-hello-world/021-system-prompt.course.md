# Lesson 23.21: System prompt (course companion)

*Explain It Like Hello World. Not for LinkedIn.*

## Learning objective

After this lesson, you can explain system prompt with a hello-world example, say how it really works in one step, and name its most common misunderstanding.

## The hello world, to retell

Before a new support agent takes their first call, the manager tells them: "You work for Acme. Be friendly. Never promise refunds. Answer only about our products."

## One step further

Every chat app sends the AI a system prompt first, then your message. It sets the role, tone, format, what to avoid and sometimes today's date or tools it can use.

The AI gives it extra weight, but it isn't unbreakable: clever user messages can sometimes push against it (write-ups 96 and 97). So real rules, like refund limits, belong in code too.

## Exercise

Explain system prompt to someone non-technical in under one minute, using your own everyday example (not the one from the article). Then name one product where they have already met it.

## Quiz

1. What is the hello-world example for system prompt? *A system prompt is that briefing, given to the AI before you type.*
2. What is it not? *A system prompt isn't a security wall or a secret vault. Don't put passwords or confidential data in it, and don't rely on it alone to enforce rules.*
3. Name one place you've already met it. *Every branded chatbot that stays "in character". Custom GPTs and assistants you set up with instructions.*

## Glossary

- **System prompt:** hidden setup instructions sent before the conversation.
- **User prompt:** what the person types.
- **Persona:** the role and tone the AI is told to take.
