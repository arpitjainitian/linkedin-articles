# Lesson 23.74: Multi-agent system (course companion)

*Explain It Like Hello World. Not for LinkedIn.*

## Learning objective

After this lesson, you can explain multi-agent system with a hello-world example, say how it really works in one step, and name its most common misunderstanding.

## The hello world, to retell

Planning a wedding alone is overwhelming. So you have a coordinator, a caterer, a decorator and a photographer, each an expert, with the coordinator keeping everyone in sync.

## One step further

A coordinator agent breaks the goal into parts and hands them out. Specialist agents work on their part with their own instructions and tools, sometimes in parallel. The coordinator combines the results.

It helps for big, varied tasks. But every hand-off can lose context or pass on errors, and several agents cost more than one. Often a single agent does the job.

## Exercise

Explain multi-agent system to someone non-technical in under one minute, using your own everyday example (not the one from the article). Then name one product where they have already met it.

## Quiz

1. What is the hello-world example for multi-agent system? *A multi-agent system is that team, made of AI agents.*
2. What is it not? *More agents isn't more intelligence. Start with one agent; split only when the task truly needs it. (Series 15 covers the pitfalls.)*
3. Name one place you've already met it. *Research tools that send several agents to read different sources at once. Coding tools with separate planner, coder and reviewer roles.*

## Glossary

- **Coordinator:** the agent that splits and assigns work.
- **Sub-agent:** a specialist agent doing one part.
- **Hand-off:** passing work or results between agents.
