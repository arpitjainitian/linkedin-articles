# 77. What Are Agent Skills, and Why Do Agents Need a Playbook? | Agent skills

![Cover](images/077-agent-skills-cover.png)

*Explain It Like Hello World series: Agent skills*

"Agent skills." "Skills." AI agents can now be handed packaged know-how, like a new joiner gets a playbook.

## The hello world

A new joiner gets a binder of how-tos: how we file expenses, how we write a client report. They don't memorise it. They open the right page when the task comes up.

That's the hello world: **agent skills** are packaged instructions, sometimes with small scripts or templates, that an AI agent loads only when a task needs them.

## One step further

Each skill has a short description plus detailed steps. The agent sees the short descriptions, and when a task matches, it opens the full skill. That keeps the agent's desk clear (write-up 27) while giving it expert steps on demand.

Skills hold know-how: how to do something. Tools (write-up 75) and MCP (write-up 76) give access: what the agent can reach. Agents usually need both.

## Where you've already met it

AI assistants that follow your company's report format or brand rules, and coding agents with team-specific playbooks.

## The real name

**Agent skills**, often just called **skills**.

- **Skill:** packaged know-how an agent loads when needed.
- **Playbook:** step-by-step instructions for a task.
- **Progressive loading:** opening the details only when they're relevant.

## What it's not

A skill isn't a new model or new training. It's instructions the same AI reads. Skills from unknown sources can carry hidden instructions, so review them like code.

## Take this to your next meeting

1. Turn your team's best how-tos into skills.
2. Keep each skill short and focused.
3. Only install skills from sources you trust.

Not memorised. Opened when needed.
