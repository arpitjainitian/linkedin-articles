# Lesson 23.64: MCP (course companion)

*Explain It Like Hello World. Not for LinkedIn.*

## Learning objective

After this lesson, you can explain MCP with a hello-world example, say how it really works in one step, and name its most common misunderstanding.

## The hello world, to retell

Before USB, every printer, camera and keyboard had its own plug. Then USB: one standard plug for everything.

## One step further

Without MCP, every AI app needed its own custom code for every tool: Slack, Google Drive, a database. With MCP, a tool provider builds one MCP server, and any compatible AI app can connect to it and discover what it offers.

Anthropic introduced MCP in late 2024, and it's now supported widely across AI tools. It makes connecting easy; deciding what's safe to connect is still your job.

## Exercise

Explain MCP to someone non-technical in under one minute, using your own everyday example (not the one from the article). Then name one product where they have already met it.

## Quiz

1. What is the hello-world example for MCP? *MCP is that one plug, between AI apps and tools.*
2. What is it not? *MCP isn't a security system or an AI model. A connected tool can still leak data or take wrong actions. What MCP doesn't solve is the theme of my Series 11.*
3. Name one place you've already met it. *AI apps and coding tools with a list of "connectors" or "MCP servers" you can switch on.*

## Glossary

- **MCP server:** a connector that exposes a tool or data source.
- **MCP client:** the AI app that connects to servers.
- **Protocol:** an agreed way of talking.
