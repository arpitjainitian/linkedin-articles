# Lesson 23.80: Decision model (course companion)

*Explain It Like Hello World. Not for LinkedIn.*

## Learning objective

After this lesson, you can explain decision model with a hello-world example, say how it really works in one step, and name its most common misunderstanding.

## The hello world, to retell

A judge on a talent show doesn't write an essay. They watch the contestants and hold up a score.

## One step further

Chat models (write-up 12) produce text. A decision model is built to compare options: which support ticket is most urgent, which offer to show, which tool an agent should use next. Its output is a choice or a score, which is easier for software to act on, log and check.

My [Today in AI No. 004](https://www.linkedin.com/pulse/today-ai-004-why-microsofts-new-built-choose-chat-meet-arpit-jain-ypmkf/) covers one example.

## Exercise

Explain decision model to someone non-technical in under one minute, using your own everyday example (not the one from the article). Then name one product where they have already met it.

## Quiz

1. What is the hello-world example for decision model? *A decision model does the same: it compares options and picks one.*
2. What is it not? *A decision model isn't someone to hide behind. People still own the choice, and should be able to explain it (write-up 102).*
3. Name one place you've already met it. *Ranking which email to answer first, choosing the next offer for a customer, and picking which step an agent takes next.*

## Glossary

- **Options:** the fixed list to choose from.
- **Score:** how strongly the model prefers each option.
- **Classifier:** an older name for models that pick a category.
