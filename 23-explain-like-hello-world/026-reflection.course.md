# Lesson 23.26: Reflection (course companion)

*Explain It Like Hello World. Not for LinkedIn.*

## Learning objective

After this lesson, you can explain reflection with a hello-world example, say how it really works in one step, and name its most common misunderstanding.

## The hello world, to retell

A student writes an answer, then rereads it before handing it in and spots a wrong sum.

## One step further

The model writes a draft, then runs a second pass that asks: is this correct, complete and in the right format? If not, it revises. Some systems use a second model as the critic, which can catch errors the first model can't see in its own work.

Reflection costs extra time and tokens. It helps most on tasks with clear checks, such as maths, code that must compile, or answers that must cite a source.

## Exercise

Explain reflection to someone non-technical in under one minute, using your own everyday example (not the one from the article). Then name one product where they have already met it.

## Quiz

1. What is the hello-world example for reflection? *Reflection is an AI checking its own draft before it answers.*
2. What is it not? *Reflection isn't a guarantee. An AI can review its own mistake and agree with it. A check against something outside the model, such as a test or a source, is more reliable.*
3. Name one place you've already met it. *Coding assistants that run their own tests and fix the errors, and AI tools that say "let me check that" before answering.*

## Glossary

- **Draft:** the first version an AI produces.
- **Critique:** a review that points out what is wrong.
- **Self-correction:** fixing your own output after checking it.
