# Lesson 23.5: Neural network (course companion)

*Explain It Like Hello World. Not for LinkedIn.*

## Learning objective

After this lesson, you can explain neural network with a hello-world example, say how it really works in one step, and name its most common misunderstanding.

## The hello world, to retell

Picture a team voting on "Is this a cat?". Each member looks at one small clue and shouts a number. Some voices count more than others. The total decides.

## One step further

Each tiny neuron takes numbers in, multiplies them by its weights (how much to trust each input), adds them up and passes the result on. Training adjusts those weights (write-up 26) until the final answer comes out right.

One neuron is trivial. Billions of them, in many layers (write-up 4), can recognise faces or write essays.

## Exercise

Explain neural network to someone non-technical in under one minute, using your own everyday example (not the one from the article). Then name one product where they have already met it.

## Quiz

1. What is the hello-world example for neural network? *A neural network is billions of tiny voters adding up numbers.*
2. What is it not? *It's loosely inspired by the brain, not a copy of one. Real brain cells are far more complex, and a neural network has no feelings or awareness.*
3. Name one place you've already met it. *Behind face unlock, voice typing, photo search and every modern chatbot.*

## Glossary

- **Neuron:** a tiny unit that adds up weighted inputs.
- **Weight:** how much a neuron trusts each input.
- **Activation:** the number a neuron passes on.
